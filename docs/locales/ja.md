# はじめまして、Opilnig です 👋

シニア・システムプログラマー、デジタル信号処理（DSP）スペシャリスト、および高性能オーディオソフトウェアエンジニアです。Rustを用いた決定論的リアルタイム・オーディオシステムの設計、モジュラーシンセサイザーのアーキテクチャ構築、WebAssemblyを活用したネイティブ性能のWebオーディオ開発に注力しています。

マイクロ秒レベルのタイミング精度、数値解析的な堅牢性、キャッシュ効率を重視したシステム設計を追求しています。ターミナルの外では、ディスクリート・アナログ回路のベンチテスト、真空管アンプの校正、独自のDSPフィルター設計に取り組んでいます。

---

## 🛠️ 専門エンジニアリング領域と設計哲学

- **決定論的リアルタイム・オーディオ**: ヒープ割り当てのない（Zero-allocation）オーディオ描画スレッド、ロックフリー・リングバッファ、音切れ（ドロップアウト）のない有界時間DSPループの実装。
- **高性能数値演算**: SIMDアクセラレーション演算カーネル（AVX2/NEON）、ゼロ遅延フィードバック（ZDF）アナログフィルター・トポロジー、非線形回路数値ソルバーの設計。
- **クロスプラットフォーム・オーディオ設計**: デスクトップ規格（CLAP、VST3）からブラウザのAudioWorkletまで移植可能なRustおよびモダンC++のコードベース構築。
- **堅牢なシステム工学**: 厳格な並行性不変性の保証、メモリ安全性、すべての対象環境における決定論的振る舞いの検証。

## 🚀 主要オープンソースプロジェクト

### 1. [pulse-dsp](https://github.com/opilnig-rgb)
> 純粋なRustで実装されたゼロアロケーション・ロックフリーのモジュラーDSPシンセサイザーエンジン。帯域制限インパルス列（BLIT）オシレーター、ゼロ遅延フィードバック・ラダーフィルター、192kHz下で1ミリ秒未満の往復遅延を実現する拡張可能なポリフォニック・パッチマトリクスを搭載。

### 2. [wasm-audio-canvas](https://github.com/opilnig-rgb)
> WebAssemblyとAudioWorkletを用い、ブラウザ上でネイティブ性能を発揮する高スループットなインタラクティブ・オーディオビジュアライザーおよびノード型モジュラーラック。SharedArrayBufferとロックフリー・アトミックキューによって駆動。

### 3. [midi2-router](https://github.com/opilnig-rgb)
> 超軽量・クロスプラットフォームのMIDI 2.0 ユニバーサルMIDIパケット（UMP）ルーターおよびプロトコルインスペクター。ノートごとの高解像度ピッチベンド、アーティキュレーション・プロファイリング、双方向デバイス探索をサポート。

### 4. [analog-modeler](https://github.com/opilnig-rgb)
> 修正節点解析法（MNA）と減衰ニュートン・ラフソン法を用いた数値解析ソルバーにより、ヴィンテージ・アナログ演算トランスコンダクタンスアンプ（OTA）およびダイオードクリッパー回路の非線形離散挙動をシミュレーション。

## 📊 コードとアーキテクチャへの哲学

```rust
pub trait AudioProcessor: Send {
    /// ヒープ割り当てやロックを排除した純粋な決定論的オーディオブロック処理
    fn process_block(&mut self, input: &[f32], output: &mut [f32], sample_rate: f64);
}
```

- **ホットパスにおけるゼロアロケーション（Zero Allocation in Hot Paths）**: リアルタイムスレッドは、malloc、ファイルI/O、ミューテックスロックによって決してブロックされてはなりません。
- **決定論的数学演算**: すべての浮動小数点計算はビットレベルで厳密であり、有界（bounded）であり、非正規化浮動小数点数（Denormal）による性能低下を防止しなければなりません。
- **オープンスタンダード**: 特定のベンダーに依存せず、オペレーティングシステム間で完全に相互運用可能なクリーンなソフトウェアを構築します。
