# はじめまして、Opilnig です 👋

システムプログラマー、デジタル信号処理（DSP）愛好家、そしてオープンソース・オーディオハッカーです。Rustによるリアルタイム・オーディオパイプラインの決定論的設計、モジュラーシンセサイザーのアーキテクチャ構築、WebAssemblyを活用した超低遅延Webオーディオの探求に注力しています。

ナノ秒単位のオーディオドロップアウト（バッファアンダーラン）の調査や、80年代のヴィンテージアナログ回路のサーキットベンディングを行っていないときは、真空管アンプの校正、独自のDSP演算カーネルの作成、低レイヤーのオーディオ基盤へのコントリビューションに時間を費やしています。

## 🛠️ 主な注力分野とエンジニアリング哲学

- **リアルタイムDSP＆音響合成**: ポリフォニック・ウェーブテーブルエンジン、物理音響モデリング、ゼロ遅延フィードバック（ZDF）アナログフィルターの設計。
- **超低遅延システム工学**: ロックフリー・リングバッファ、SIMDアクセラレーション演算カーネル、GCによる停止を排除した決定論的メモリ管理。
- **組込み＆Webオーディオ架け橋**: Rust製のDSPコードベースを、デスクトップネイティブのVST3/CLAPプラグインおよび高性能なWebAssembly/AudioWorkletモジュールへクロスコンパイル。

## 🚀 進行中のプロジェクトと実験

### 1. [pulse-dsp](https://github.com/opilnig-rgb)
> モダンRustでゼロから実装されたゼロアロケーション・ロックフリーのモジュラーDSPシンセサイザーエンジン。帯域制限インパルス列（BLIT）オシレーター、ゼロ遅延フィードバック・ラダーフィルター、192kHzサンプリングレート下で1ミリ秒未満の往復遅延を実現する拡張可能なパッチマトリクスを搭載。

### 2. [wasm-audio-canvas](https://github.com/opilnig-rgb)
> WebAssemblyとAudioWorkletを用い、ブラウザ上でネイティブ性能を発揮する高スループットなインタラクティブ・オーディオビジュアライザーおよびノード型モジュラーラック。SharedArrayBufferとロックフリー・アトミックキューによって駆動。

### 3. [midi2-router](https://github.com/opilnig-rgb)
> 超軽量・クロスプラットフォームのMIDI 2.0 ユニバーサルMIDIパケット（UMP）ルーターおよびパケットインスペクター。ノートごとの高解像度ピッチベンド、アーティキュレーション・プロファイリング、双方向デバイス探索をサポート。

### 4. [analog-modeler](https://github.com/opilnig-rgb)
> 修正節点解析法（MNA）とニュートン・ラフソン法を用いた数値解析ソルバーにより、ヴィンテージ・アナログ演算トランスコンダクタンスアンプ（OTA）およびダイオードクリッパー回路の非線形離散挙動を忠実にシミュレーション。

## 📊 コードとクラフトマンシップへの哲学

```rust
pub trait AudioProcessor: Send {
    /// ヒープ割り当てを行わない純粋な決定論的オーディオブロック処理
    fn process_block(&mut self, input: &[f32], output: &mut [f32], sample_rate: f64);
}
```

- **ホットパスにおけるゼロアロケーション（Zero Allocation in Hot Paths）**: オーディオ描画スレッドは、malloc、ファイルI/O、ミューテックスロックによって決してブロックされてはなりません。
- **決定論的数学演算**: すべての数値計算はビットレベルで厳密であり、有界（bounded）であり、非正規化浮動小数点数（Denormal floats）の発生を防止しなければなりません。
- **オープンスタンダード**: 特定のベンダーにロックインされず、クロスプラットフォームで相互運用可能なオープンツールチェーンを構築します。
